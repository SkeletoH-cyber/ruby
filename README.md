# Ruby Mod (Fabric 1.21.1)
Сборка: установите JDK 21, затем в папке проекта:
    gradle wrapper
    ./gradlew build        (Windows: gradlew.bat build)
Готовый .jar будет в build/libs/rubymod-1.1.0.jar
Положите его в папку mods вместе с Fabric Loader и Fabric API 1.21.1.

## Рубиновая корова (v1.1.0)
- Яйцо призыва — во вкладке «Рубиновый мод».
- Появляется в равнинах, лугах и лесах.
- Раз в 5–10 минут откладывает рубин, размножается пшеницей, доится ведром.
- С убитой игроком падает рубин (0–2), кожа и говядина.
